A `task.Channel<T>(n)` passes values between tasks in FIFO order, with room for `n` values (`0`:
unbuffered). [Async and concurrency](/docs/learn/async#channels) covers the rules. Where several
tasks send to one channel, these programs sort what they receive, because the arrival order depends on
scheduling.
