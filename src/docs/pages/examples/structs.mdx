Short programs built around structs: constructors, methods that change their receiver, pointers,
embedding and printing. [Structs and methods](/docs/learn/structs) explains the rules behind them.

## A constructor that validates

A `static func` belongs to the type. One that can fail returns `T!`, so the caller cannot get an
invalid value.

## Methods that change state

Inside a method `this` points at the original, so `Push` and `Pop` change the variable they are called
on.

## Pointers: a linked list

`new Node{...}` allocates on the heap and returns a `*Node`; `nil` ends the list. A type that points to
itself could form a cycle, so the compiler warns about it; `@allowCycle` records that this code never
links a node back.
