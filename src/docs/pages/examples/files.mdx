Reading and writing files takes one call each: `io.ReadFile` and `io.WriteFile` work on whole files,
`os.Open` and `os.Create` give a `File` for streaming, and `fs` handles paths and directories. Every
program here works in its own directory under `fs.TempDir()` and removes it at the end.

## Line by line

`io.ReadLines` loads all lines at once. An `io.Scanner` over an open file reads one line at a time, so
memory use does not grow with the file.

<Example id="examples/files/lines" />

## Open files

`os.Create` truncates or creates; `os.OpenFile` takes flags such as `os.O_APPEND`. `Close` returns
`void!`, so a write error that shows up only on close is not lost.
