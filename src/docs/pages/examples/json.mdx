`encoding.json` converts between JSON text and your own types. `json.Format` and `json.Parse<T>` are
generated at compile time from the type's fields, so there are no tags to parse at run time, and
`json.ParseValue` reads JSON of unknown shape. Every program here starts with `import encoding`.
For a task-oriented walk-through see [Work with JSON](/docs/guides/json).

## Field attributes

`@json(name: …)` renames a field, `omitEmpty` leaves out zero values, `skip` excludes the field both
ways. Attributes are checked by the compiler: a misspelled option does not compile.
