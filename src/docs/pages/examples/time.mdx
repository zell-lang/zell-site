The `time` namespace follows Go's `time` package: a `Duration`, a `Time` with a location, layouts
written with the reference date `Mon Jan 2 15:04:05 2006`, and tickers and timers for async code. The
examples use fixed dates so their output never changes.

<Callout type="go">
A few names differ from Go because older integer-millisecond functions took them: `time.Current()` is
`time.Now()`, `time.Elapsed(t)` is `time.Since(t)`, `time.ParseTime` is `time.Parse`, and durations are
built with `time.Seconds(n)`, `time.Minutes(n)` and so on rather than `n * time.Second`.
</Callout>
