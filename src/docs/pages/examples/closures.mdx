Functions are values: you store them in variables, maps and slices, pass them as arguments and return
them. A closure keeps the variables it uses alive. [Basics](/docs/learn/basics#function-values-and-closures)
covers the syntax.

## Function values

A function type is written `func(int, int) int`. Named functions, short lambdas and block lambdas all
fit it.
