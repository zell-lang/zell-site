Calling an `async` function starts a task; `await` waits for its result. These programs show common
concurrency patterns. [Async and concurrency](/docs/learn/async) explains tasks, `task.All`,
cancellation and timeouts.

## CPU work on several cores

A task that never awaits runs on the caller's thread. `task.Spawn` puts it on a worker thread, so
chunks of CPU-bound work run in parallel.

## Waiting with a deadline
