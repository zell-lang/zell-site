A `map[K]V` is a hash table with reference semantics, like a Go map. Iteration order is unspecified, so
every example that prints entries sorts the keys first with `maps.SortedKeys`. The rules are in
[Collections](/docs/learn/collections).

## Basics

Index to read or write, `delete` to remove. Reading a missing key gives the zero value.
