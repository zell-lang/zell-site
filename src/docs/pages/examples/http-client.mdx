`net.http` has an asynchronous HTTP/1.1 and HTTP/2 client. Each program here first starts a small
server on `127.0.0.1` with a free port, so it runs without internet access; replace `srv.URL()` with a
real address in your own code. Every program has `import net` and an `async func main`.
