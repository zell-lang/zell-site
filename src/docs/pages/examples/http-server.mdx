An `http.Server` serves a `Handler`, usually an `http.Router`. Every connection is a task, and a
handler is an `async` function that fills in the response. To keep the output reproducible, each
program sends a few requests to its own server and then shuts it down; a real service would just
`await srv.Serve()?`.

## Middleware

A middleware is a `func(http.Handler) http.Handler`; `r.Use` wraps every route, outermost first. The
standard library has `http.Logging`, `http.Recover`, `http.CORS`, `http.Gzip` and others.

<Callout type="warning">
In 0.1.5 the 500 response body includes the error message. Do not let internal details, such as
database errors, reach a handler's return in a public service: log them and send a generic message.
</Callout>
