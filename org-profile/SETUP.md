# GitHub organization profile

Files for the zell-lang organization page on GitHub. They are not part of the site build.

1. Create a public repository **`zell-lang/.github`** and copy `profile/` into it
   (`profile/README.md` is what GitHub shows on https://github.com/zell-lang).
2. Organization settings → Profile:
   - **Picture**: `avatar.png` (512×512)
   - **Display name**: Zell
   - **Description**: A compiled language for services and tools: Go's simplicity, C#'s expressiveness, no GC pauses.
   - **URL**: https://zell-lang.org
   - **Email**: a public contact address (optional)
3. https://github.com/zell-lang → Customize pins: `zell`, `web`, `db`, `example-web-service`,
   `zell-idea-plugin`, `zell-site`.
4. Repository topics on `zell`: `zell`, `programming-language`, `compiler`, `llvm`.
